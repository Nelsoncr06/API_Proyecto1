API RESTful para
gestión de usuarios.

Servicio desarrollado con ASP.NET Core y conectado a SQL Server. Proporciona operaciones para registrar, consultar, actualizar y desactivar usuarios, además de validar credenciales de inicio de sesión.

Probar endpoint de usuarios ↗
GET
/api/Usuarios
Consultar la lista de usuarios activos.
POST
/api/Usuarios
Registrar un nuevo usuario enviando un cuerpo JSON.
POST
/api/Usuarios/ObtenerUsuarioPorId
Consultar un usuario mediante su identificador.
PUT
/api/Usuarios
Actualizar los datos de un usuario existente.
DELETE
/api/Usuarios
Desactivar un usuario usando su identificador.
POST
/api/InicioSesion
Validar las credenciales enviadas en formato JSON.

Nota: los endpoints que reciben datos deben probarse con un cliente HTTP, como Postman, enviando Content-Type: application/json y el cuerpo correspondiente. Esta página es una portada informativa; no reemplaza la documentación técnica de la API.
